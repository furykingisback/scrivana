**İçerik:**

https://github.com/furykingisback/scrivana

I built Scrivana, a free and open-source desktop PDF + Word editor. Everything runs 100% offline — no cloud, no subscriptions, no data leaves your machine.

Features:
- Rich text editor (Tiptap) with tables, images, formatting
- PDF tools: merge, split, compress, watermark, page numbers, encryption
- PDF page editor: reorder, delete, rotate pages, add text/highlights
- OCR via Tesseract.js (English + Turkish)
- Word (.docx) import/export with template variables
- Command palette, dark/light themes

Tech: Electron 33, Next.js 15, React, TypeScript, pdf-lib, pdfjs-dist, Tesseract.js.

MIT licensed. Windows builds available now, Linux/macOS welcome as PRs.
